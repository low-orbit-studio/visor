OTPInput takes five size hooks for its cells: `--otp-cell-width`, `--otp-cell-height`, `--otp-cell-font-size`, `--otp-cell-radius` and `--otp-gap`. Each falls back to today's value, so unbound renders unchanged. `--otp-cell-width: 100%` on a widened component stretches the cells to share the row.
