## Installation

```bash
npx visor add option-cards
```

This copies two files into your project:

- `components/ui/option-cards/option-cards.tsx` — the component
- `components/ui/option-cards/option-cards.module.css` — the styles

## Usage

```tsx
import { OptionCards } from '@/components/ui/option-cards/option-cards';

const [pick, setPick] = React.useState<number | null>(null);

<OptionCards
  aria-label="Hosting"
  value={pick}
  onValueChange={setPick}
  options={[
    { label: 'Keep Vercel', detail: 'As today.', pros: ['No setup'], cons: ['Per-seat cost'], recommended: true },
    { label: 'Self-Host', detail: 'Our own box.', pros: ['No bill'], cons: ['We run upgrades'] },
  ]}
/>
```

Pass `value` and `onValueChange` to control it, or `defaultValue` to leave it uncontrolled. The selection is the picked option's index, or `null` before anything is picked.

## Behavior

- **Recommended.** Only the first option with `recommended` gets the mark, so a row never recommends two.
- **Selection ring.** One ring slides to the picked card on a CSS transition. Under `prefers-reduced-motion: reduce` it moves without sliding.
- **Keyboard.** The group is one tab stop. Arrow keys move and select, wrapping at the ends. While focus is in the group, the A, B, C and D keys pick that card directly.
- **Layout.** Cards sit side by side, and stack once the component is narrower than 900px (a container query, so a narrow column stacks too).
- **Colour.** Every colour is a theme token: the card is a tile a half-step off `--surface-page` toward the ink, ink and the ring are `--text-primary`, pros and the Recommended mark are `--text-success`, cons are `--text-warning`.
