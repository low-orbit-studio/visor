## Option Rows

`variant="option"` draws each item as a full-width row you tap to pick: a lettered key on the left
(A, B, C…, filled when picked), the label, and in a multiple group a check box on the right. There
is no radio dot; the whole row is the target. The group keeps ToggleGroup's semantics: a single
group is a radiogroup, a multiple group a group of pressed buttons, arrow keys move between rows and
Space or Enter picks. Add `shortcuts` and the letters work as keys while focus is in the group.

## Installation

```bash
npx visor add toggle-group
```

This copies two files into your project:

- `components/ui/toggle-group/toggle-group.tsx` — the component
- `components/ui/toggle-group/toggle-group.module.css` — the styles

## Usage

```tsx
import { ToggleGroup, ToggleGroupItem } from '@/components/ui/toggle-group/toggle-group';

<ToggleGroup type="single">
  <ToggleGroupItem value="a">A</ToggleGroupItem>
  <ToggleGroupItem value="b">B</ToggleGroupItem>
</ToggleGroup>
```

## Sub-components

| Component | Element | Purpose |
| --- | --- | --- |
| `ToggleGroup` | `<div>` | Root group container with variant/size context and optional sliding indicator |
| `ToggleGroupItem` | `<button>` | Individual toggle button inheriting variant and size from the group. In the option variant it renders the key, label and (multiple) check |

## Accessibility

- Built on `@radix-ui/react-toggle-group`. A single-select group has `role="radiogroup"` with `role="radio"` items and `aria-checked`; a multi-select group stays a `group` of `aria-pressed` buttons
- Keyboard focus draws a solid `--border-focus` ring at `--focus-ring-width`, offset by `--focus-ring-offset`, on every item
- Provide an `aria-label` on `<ToggleGroup>` to describe the purpose of the group (e.g., "Text formatting", "View mode")
- Keyboard: Arrow keys navigate between items within the group; Space/Enter toggles the focused item
- Option variant: the letter key and the check box are `aria-hidden`, so each row is named by its label alone. With `shortcuts`, a letter key (no modifier) picks and focuses the row at that position; a disabled row ignores it

## Theming

A theme sets the group's look with the `toggle-group` keys, so no tokens go on the group itself: the
outline track's fill, the selected option's fill and ink, the unselected ink, and the compact (`xs`)
label size, option sides and corners. Every key falls back to what the group read before, so a theme
that sets none of them renders as it always has. A compact group on a dark well, the selected option
in a soft accent wash:

```yaml
components:
  toggle-group:
    track-bg: "rgba(0, 0, 0, 0.65)"
    selected-bg: "rgba(44, 224, 230, 0.09)"
    selected-text: "#2ce0e6"
    unselected-text: "rgba(255, 255, 255, 0.46)"
    xs-font-size: 10px
    xs-padding-x: 11px
    xs-track-radius: 8px
    xs-item-radius: 6px
```

The option variant has its own `option-*` keys: the row's gap, height, padding, corners, fill
(rest, hover and picked), picked ring, backdrop blur, ink and type; the letter key's size, corners,
edge, ink and type; the picked key and check fill (`option-mark-bg`, `option-mark-text`); and the check
box's size, corners and edge. The defaults are Visor's tokens. Glass rows over a photo, in a dark theme:

```yaml
components:
  toggle-group:
    option-min-height: 54px
    option-padding: 10px 18px 10px 13px
    option-radius: 12px
    option-bg: "rgba(255, 255, 255, 0.09)"
    option-hover-bg: "rgba(255, 255, 255, 0.13)"
    option-selected-bg: "rgba(255, 255, 255, 0.2)"
    option-selected-ring: "rgba(255, 255, 255, 0.4)"
    option-blur: 24px
    option-font-size: 17px
    option-key-radius: 8px
    option-mark-bg: "#e8457c"
    option-mark-text: "#ffffff"
    option-check-radius: 6px
```

The full list, with each fallback, is in [Component Tokens](/docs/themes/component-tokens#toggle-group).

## Label Centering

The label is optically centred in any font: its line box is trimmed to the capital-height band, so capitals (not the font's ascent and descent) sit on the box centre, with the box size unchanged. Firefox keeps the previous rendering. Shared spec: [`docs/label-centering.md`](https://github.com/low-orbit-studio/visor/blob/main/docs/label-centering.md).
