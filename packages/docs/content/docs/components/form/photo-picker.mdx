## Default

Each thumbnail is a button with `aria-pressed`; the chosen one wears a 2px ring and every image grows a little on hover. The thumbnails rise in a quick wave from the top left when the grid mounts and every time `play` changes. Here a counter replays it.

## In a Popover

The picker is only the grid, so it sits in whatever popover or panel you bring. Pass the open state to `play` so the wave replays on every open, and to `load` so no thumbnail is fetched before the first open. Once loaded, thumbnails stay loaded.

## In Five Looks

The grid takes its colours and corners from the theme: the resting ring is the theme's border, the chosen ring its key colour (`--interactive-primary-bg`), and the thumbnails take the theme's corner shape. It draws no surface of its own, so over a photo it sits in a glass panel or popover (see [Glass](/docs/themes/glass)). ## Installation

```bash
npx visor add photo-picker
```

This copies two files into your project:

- `components/ui/photo-picker/photo-picker.tsx` — the component
- `components/ui/photo-picker/photo-picker.module.css` — the styles

## Usage

```tsx
import { PhotoPicker } from '@/components/ui/photo-picker/photo-picker';

const photos = [
  { key: 'dusk', thumb: '/photos/dusk-480.webp', label: 'Dusk at the stage' },
  { key: 'lake', thumb: '/photos/lake-480.webp' },
];

<PhotoPicker aria-label="Pick Your Background" photos={photos} value={photo} onValueChange={setPhoto} play={open} load={open} />
```

## Theming

| Variable | Default | Sets |
|---|---|---|
| `--photo-picker-columns` | `5` | Columns above 760px |
| `--photo-picker-columns-narrow` | `3` | Columns at 760px and under |
| `--photo-picker-gap` | `--spacing-2` (8px) | Gap between thumbnails |
| `--photo-picker-padding` | `--spacing-1` (4px) | Room for the chosen ring inside the scroll box |
| `--photo-picker-max-height` | `min(62vh, 560px)` | Height before the grid scrolls |
| `--photo-picker-radius` | `--radius-xl` | Thumbnail corner radius |
| `--photo-picker-ring` | `--border-default` | The 1px inset ring before a thumbnail loads |
| `--photo-picker-ring-selected` | `--interactive-primary-bg` | The chosen thumbnail's 2px ring |
| `--photo-picker-ease` | `--motion-easing-enter` | The wave's and the hover's easing |
| `--photo-picker-draw-duration` | 320ms (`--motion-duration-enter`, else `--motion-duration-800`, × 0.4) | Each thumbnail's rise |
| `--photo-picker-draw-gap` | `48ms` | The beat between neighbours |
| `--photo-picker-draw-rise` | `10px` | How far each thumbnail rises |

Thumbnails are 4:3 and scale to 1.08 on hover. For anything else, target the buttons through your own `className`.

## Accessibility

- The grid is `role="group"`; give it an `aria-label` or `aria-labelledby` (4.1.2)
- Each thumbnail is a native button with `aria-pressed`, named by its `label` or "Photo N" (4.1.2)
- The chosen thumbnail is marked by a ring as well as by `aria-pressed`, and focus draws its own ring at the focus-ring tokens (2.4.7)
- With `prefers-reduced-motion: reduce`, the wave and the hover zoom are off (2.3.3)
