## Invalid

`invalid` marks every cell `aria-invalid` and draws the invalid edge. The digits stay, so the code can be fixed. `errorMessage` is shown under the cells in the error text colour and announced as a `role="alert"` live region. Do not also render your own error line when you pass it.

<ComponentPreview
  title="Invalid"
  code={"<OTPInput length={6} value=\"428519\" invalid errorMessage=\"That code is not right.\" />"}
>

</ComponentPreview>

## Sizing Hooks

Five CSS variables size the cells. Set them on the component, or on any ancestor from a theme. Unset, each falls back to the default size.

| Variable | Sets | Default |
|----------|------|---------|
| `--otp-cell-width` | Cell width. `100%` stretches the cells to share the row equally. | `2.5rem` |
| `--otp-cell-height` | Cell height | `2.75rem` |
| `--otp-cell-font-size` | Digit size | `var(--font-size-lg)` |
| `--otp-cell-radius` | Cell corner radius | `var(--radius-md)` |
| `--otp-gap` | Space between cells | `var(--spacing-2)` |

To stretch the cells, set `--otp-cell-width: 100%` and give the component a width (here `width: 100%`). The cells then split that width, less the gaps.

## Installation

```bash
npx visor add otp-input
```

This copies two files into your project:

- `components/ui/otp-input/otp-input.tsx` — the component
- `components/ui/otp-input/otp-input.module.css` — the styles

## Usage

```tsx
import { OTPInput } from '@/components/ui/otp-input/otp-input';

<OTPInput length={6} onChange={(code) => console.log(code)} />
```

## Accessibility

- Each digit cell renders as `type="text"` with `inputmode="numeric"` and `maxlength="1"`
- Cells are grouped inside a `<div role="group">` with an accessible label (e.g., `aria-label="One-time password"`)
- Focus auto-advances to the next cell on digit entry and moves back on Backspace
- The first cell carries `autocomplete="one-time-code"`, so a one-time-code autofill fills every cell (WCAG 3.3.8)
- `invalid` sets `aria-invalid` on every cell; `errorMessage` is shown under the cells and is the `role="alert"` live region (4.1.3, 1.4.1)
- Paste support fills all cells from clipboard and focuses the last filled cell
- Provide a descriptive `aria-label` prop on the group for screen reader context (e.g., "Enter your 6-digit verification code")
