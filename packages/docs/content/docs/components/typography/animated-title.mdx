Each word is its own span with a CSS animation; word *i* starts at `delay + i × stagger`. There is no
animation library and no timer, so server and client markup match. The title plays once when it mounts:
press Replay to watch it again.

## Blur

The default. Each word lifts 6px into focus from a 14px blur as it fades in: 1.1s per word, 60ms apart.

## Weight

Each word fades in from weight 300 and settles at 520: 1.3s per word, 50ms apart. The settled weight is a
plain rule, so the title looks the same with or without motion.

## Hold and Start Delay

`play={false}` holds every word on its first frame, hidden, until you set it to `true`. `delay` (ms) waits
before the first word starts. Replay by changing the title's `key`.

## Installation

```bash
npx visor add animated-title
```

This copies two files into your project:

- `components/ui/animated-title/animated-title.tsx` — the component
- `components/ui/animated-title/animated-title.module.css` — the keyframes and settings

## Usage

```tsx
import { AnimatedTitle } from '@/components/ui/animated-title/animated-title';

export default function Intro() {
  return <AnimatedTitle as="h1" text="Tell us about your weekend" />;
}
```

## Settings

Set these on the title or any ancestor. The defaults are the Honcho kit's numbers, deliberately not
motion-scale steps, so the title moves the same in every theme. The curve is the theme's
`--motion-easing-enter`.

| Variable | Default | What it sets |
| --- | --- | --- |
| `--animated-title-duration` | 1.05s rise, 1.1s blur, 1.3s weight | Each word's run |
| `--animated-title-stagger` | 55ms rise, 60ms blur, 50ms weight | The gap between one word's start and the next |
| `--animated-title-delay` | 0ms | Before the first word starts (the `delay` prop) |

## Exit

CSS can't animate an element as it unmounts. To animate the title out, wrap it in your app's own motion item.

## Accessibility

- The element holds the full title once, in a visually hidden copy; the animated words sit in an `aria-hidden` wrapper, so a screen reader reads the title once
- Under `prefers-reduced-motion: reduce` the words have no animation and show settled
- Each word has 0.2em of room above and below, so accents and descenders are never clipped while it animates
- AnimatedTitle sets no colour: the title takes the surrounding text colour
