## Glass and Editable

`variant="glass"` draws the card on two layers placed before its content: a glass fill and an edge. Glass is off by default. Inside `data-glass="on"` (see [Glass](/docs/themes/glass)), the fill turns see-through, blurs the photo behind it and takes the theme's lift, and the edge blends `soft-light` with the photo. Everywhere else the layers draw the card surface and a plain border, with no blur.

Because the layers are siblings of the content, never its ancestors, a blurred field inside the card (the stepper below) still blurs the photo rather than the card. Keep it that way: put no `filter`, `backdrop-filter`, `opacity` below 1, `mask`, `transform` or blend mode on anything between a blurred field and the photo.

`editable` makes the whole card a button (`type="button"`). It gets a pen in the top-right corner, and on hover the fill steps up, the shadow deepens and the pen fills with the theme's key colour (`--interactive-primary-bg`). The card does not move on hover; it presses in slightly while held. Keyboard focus draws an outline in the key colour, and Enter or Space activates it. After a save, set `data-flash` on the card to play a 1.6s ring in the key colour. To replay it, remove the attribute, force a reflow and set it again. The corner shape comes from the theme's `corners`.

## Installation

```bash
npx visor add card
```

This copies two files into your project:

- `components/ui/card/card.tsx` — the component
- `components/ui/card/card.module.css` — the styles

## Usage

```tsx
import {
  Card, CardHeader, CardTitle, CardDescription,
  CardContent, CardFooter,
} from '@/components/ui/card/card';

<Card>
  <CardHeader>
    <CardTitle>Title</CardTitle>
    <CardDescription>Description text.</CardDescription>
  </CardHeader>
  <CardContent>
    <p>Body content here.</p>
  </CardContent>
  <CardFooter>
    <Button>Action</Button>
  </CardFooter>
</Card>
```

## Accessibility

- Card is a presentational container — it does not add any ARIA roles by default.
- Use semantic heading elements inside `CardTitle` when appropriate for document outline.
- An `editable` card is a native `<button type="button">`: it is in the tab order, Enter and Space activate it, and focus draws an outline in the key colour. Give it an accessible name (`aria-label`, or text inside). Keep its content to phrasing elements (`<span>`), and put no other control inside it.
- The glass layers and the pen are `aria-hidden`.
- Under `prefers-reduced-motion: reduce` the press does not scale and colour changes are instant.
- Interactive cards that navigate should wrap the entire card in an anchor.
