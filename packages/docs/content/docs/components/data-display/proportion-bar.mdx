## Default

Pass `parts`, each a `label` and a `value`. Each part's width is its share of the total. Parts are
told apart by the ground showing between them, never by a line, and only the outer ends round.
`legend` adds a row under the bar: swatch, label, value. `formatValue` formats every value the bar
shows or says.

## Thin

`size="thin"` draws the bar 8px tall with full pill ends, for a summary inside a card. The default
is 30px, for a main balance.

## Fills

Without `fill`, a part takes `--proportion-bar-fill-1` to `-4` by its position (the fifth takes
`fill-1` again). Three fills are built in:

- `hatched`: diagonal strokes, for time or money that does not count (not billable, written off).
- `striped`: two close tones in alternating bands, for money earned and not yet collected.
- `alert`: the theme's alert fill, for the one part that needs a decision. Its legend label and
  value read in the alert text colour, so the part is named in text as well as by its fill.

Any other string is used as the part's CSS `background`: a colour, a `var()`, or a gradient. A part
narrower than 4px still draws at 4px so it can be hovered (the last part below); its value is in
the legend and its tooltip.

## Theming

Every colour is a `proportion-bar` component token (`components.proportion-bar` in `.visor.yaml`).
Unbound, the default fills read the chart palette.

| Token | Drives | Unbound |
| --- | --- | --- |
| `--proportion-bar-fill-1` … `-4` | Default part fills by position | `--chart-1` … `--chart-4` |
| `--proportion-bar-hatch-color`, `--proportion-bar-hatch-gap` | The `hatched` strokes and the ground between them | `--text-tertiary`, the card at 70% |
| `--proportion-bar-stripe-a`, `--proportion-bar-stripe-b` | The `striped` bands | `--color-success-500`, `--color-success-600` |
| `--proportion-bar-alert-bg`, `--proportion-bar-alert-text` | The `alert` fill and its legend text | `--interactive-destructive-bg`, `--text-error` |
| `--proportion-bar-track-bg` | The empty track | `--surface-muted` |

Paper binds them to its money and hours colours: Slate in light and Deep ocean at night for the
fills, Tide for `fill-4`, Emerald stripes for `striped`, and coral for `alert`. Every fill but coral
clears 3:1 on the card; coral is under 3:1 on the light card, which is why the legend names it in
text.

## Installation

```bash
npx visor add proportion-bar
```

This copies two files into your project:

- `components/ui/proportion-bar/proportion-bar.tsx` — the component
- `components/ui/proportion-bar/proportion-bar.module.css` — the styles

## Accessibility

- The bar is one `role="img"` whose accessible name sums it: "186.5 h: On a package 92.25 h,
  Outside a package 41.5 h, …". Pass `summary` to say it differently.
- The legend is a plain list after the bar, readable as text.
- Each part carries a `title` with its label and value, so a sliver can be hovered.
- The alert part is named in the alert text colour, never by its fill alone.
