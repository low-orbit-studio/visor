## Selectable band (a filter)

Pass `value`, `defaultValue` or `onValueChange` and the band becomes a filter: a radiogroup whose cells are radios, one pressed. Each cell draws its value over a sentence-case caption, and the pressed plate slides between cells. Arrow keys move focus and selection together; the band is one tab stop. The cell `id` is the value reported by `onValueChange`.

## Installation

```bash
npx visor add infographic-bar
```

This copies two files into your project:

- `components/ui/infographic-bar/infographic-bar.tsx` — the component
- `components/ui/infographic-bar/infographic-bar.module.css` — the styles

`StatCard` and `ToggleGroup` (the selectable band's radiogroup) are installed automatically as dependencies.

## Usage

```tsx
import { InfographicBar } from '@/components/ui/infographic-bar/infographic-bar';

export default function Example() {
  return (
    <InfographicBar
      stats={[
        { label: 'Total Revenue', value: '$48,120', delta: { value: '+12.4%', direction: 'up', label: 'vs last month' } },
        { label: 'Active Users', value: '892', delta: { value: '+3.1%', direction: 'up' } },
        { label: 'Churn Rate', value: '3.2%', delta: { value: '-0.4%', direction: 'down' } },
      ]}
    />
  );
}
```

## Theming

InfographicBar is theme-agnostic and reads correctly in both bordered and borderless palettes:

- **Outer frame** uses `--border-default`. Borderless themes set this to `transparent`, so the band's frame drops away and it melts into the page.
- **Dividers** use `--hairline` — the house soft-separator token, lighter than a full border. Override `--infographic-bar-divider` to retune them, including `transparent` for a fully seamless band.
- **Corners** round via `overflow: hidden` on the band, so outer cells round and inner cells stay square for any number of cells.

The selectable band has no border and sits on one tint:

- **Band** is the page mixed 6% toward the ink (`--infographic-bar-bg`); on a pure-black page a 3% white layer fades in so the band still reads.
- **Pressed plate** is a lifted plate on a light page (the page mixed 60% toward white, plus `--shadow-sm`) and a 9% ink wash in dark. It reads the page and the ink, not a mode class, so an always-dark theme's light mode still gets the wash. Override with `--infographic-bar-plate-bg` and `--infographic-bar-plate-shadow`.
- **Size** follows the approval-inbox drawing: a 4px inset with concentric inner corners (`--radius-xl` less the inset, `--infographic-bar-radius` to retune), cells at least 124px wide (`--infographic-bar-cell-min-width`), a 44px count (`--infographic-bar-value-size`) and a 13px caption (`--infographic-bar-caption-size`). Below 720px the band spans its container and the count drops to 32px.

### InfographicBarProps

<PropsTable component="infographic-bar" />

The component also forwards all standard HTML attributes to the band `<div>`.

### InfographicBarStat

Each entry in `stats` is a subset of [`StatCardProps`](/docs/components/admin/stat-card): `label`, `value`, `delta`, `trend`, `trendPosition`, `footer`, `variant`, `valueAs`, plus an optional `id` used as the React key.

## Accessibility

Each cell is a `StatCard`, which announces its delta direction (`up`, `down`, `flat`) to screen readers via visually-hidden text alongside the visible glyph — color is never the sole signal. The cells default to `<article>` landmarks, so the band exposes one landmark per metric.

A selectable band is a `radiogroup` (name it with `aria-label`); each cell is a `radio` with `aria-checked`, named by its value and caption ("7 waiting"). Arrow keys move focus and selection together, and the band is one tab stop.
