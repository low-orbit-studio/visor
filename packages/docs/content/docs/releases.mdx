## Marketing FX — Runtime-Keyed Accent Bridge

Visor's CSS var-chain architecture enables a **runtime-keyed accent bridge**: a one-line unlayered CSS rule that makes every interactive Visor atom track a runtime-animated variable live, including per-frame OKLab crossfades.

This pattern is now a first-class, documented, and CI-guarded Visor feature. See [Runtime-Keyed Accent Bridge](/docs/guides/runtime-accent-bridge) for the bridge block, per-scope override recipe, safe token families, and the CI guard that protects the var-chain contract.

The Blacklight marketing site's OKLab hero-carousel crossfade is the canonical reference implementation (BL-325). Link will be added when that wave lands.
