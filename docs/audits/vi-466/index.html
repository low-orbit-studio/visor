BL-193 alpha-overlay treatments

Every value below is taken verbatim from blacklight-underground/theme.visor.yaml → overrides.dark. The theme is dark-only, so this is the only mode that matters. This page hardcodes the values because the engine doesn't emit 6 of them yet (the T4 prereq) — it shows what they'll look like once it does.

For the genuinely-new tokens (brand soft/glow/strong, status *-soft) I've laid out multiple applied possibilities. Tell me which option(s) to standardize — your picks become the merged ticket's acceptance criteria.

1 · Surface ladder

page/muted/card emit todayelevated → reuse surface-elev

Four distinct tiers — recessed → raised. surface-subtle is the alpha tint used for hairline fills. The explorer's current Surface demo points at undefined --surface-primary/secondary/tertiary and renders blank; this is the real ladder it should show.
